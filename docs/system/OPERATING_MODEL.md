# Operating Model

Product work moves through:

`Brief -> Architecture -> Roadmap -> current phase -> verification -> handoff`

The coding agent owns normal implementation decisions. The user owns product changes, branding decisions that matter commercially, and any permission/privacy expansion.

A normal session works on one current phase and 1–3 cohesive tasks. Phase status is determined by acceptance criteria, not task count.

External docs are evidence, not the project source of truth. Important conclusions should be folded into canonical project docs or a small research note.
