# Session Handoff

After meaningful work:

1. verify current phase acceptance criteria;
2. classify result as `IN PROGRESS`, `PHASE COMPLETE`, or `PROJECT COMPLETE`;
3. update the phase marker in `docs/project/ROADMAP.md`;
4. update `docs/project/NEXT_SESSION.md`;
5. provide a ready-to-copy next prompt.

If authenticated ChatGPT manual QA is unavailable, name the blocked criterion and keep the phase incomplete.

When a phase completes, move `[>]` to the next planned phase. When all phases are `[x]`, mark the project complete and route to release/audit.
