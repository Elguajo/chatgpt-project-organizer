# Tool profile

Core project workflow: repository docs + native coding tools.

Recommended on demand:

- Context7 — current library/API docs.
- Superpowers-style workflow — TDD, debugging and implementation discipline.
- Semble — semantic code discovery after the codebase grows.
- Serena — symbol/reference/refactor work.
- RTK — compact noisy terminal output.
- gstack/browser review tooling — review and release QA.
- GitHub Spec Kit — optional deep phase formalization only.

Installed does not mean always invoked.
