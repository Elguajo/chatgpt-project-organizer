# Setup Recommended Tooling

For ProjectPins:

Required:
- Node/npm
- WXT/TypeScript
- Vitest
- Playwright
- Python audit
- Chrome/Chromium

Optional AI tools are listed in `docs/project/TOOLING_STATUS.md`.

Do not install global hooks or external agent tools unless the user/agent environment benefits from them. Product work must not depend on an optional tool being available.
