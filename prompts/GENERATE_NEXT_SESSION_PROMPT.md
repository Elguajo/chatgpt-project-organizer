# Generate Next Session Prompt

Use ROADMAP as canonical status.

Create a short prompt that tells a fresh coding agent:

- which phase to read;
- the next 1–3 cohesive tasks;
- key constraints that are easy to violate;
- required verification;
- known external blocker if any;
- requirement to update ROADMAP + NEXT_SESSION.

Reference canonical files instead of retelling the whole project.
